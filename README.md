# YouTube Skills

A public collection of agent skills for YouTube production, video editing, and motion graphics.

## Skills

| Skill | Description |
|---|---|
| [after-effects-scripting](after-effects-scripting/SKILL.md) | Speeds up After Effects scripting with reusable tools and best practices. |

## Install

```bash
git clone https://github.com/MaciejDziubaOrg/youtube-skills.git
ln -s "$PWD/youtube-skills/after-effects-scripting" ~/.agents/skills/after-effects-scripting
```
